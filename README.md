# Linux Production Support Lab v1
Linux Production Support Lab is a hands-on operations project that simulates maintaining a small production application on a Linux server. The project focuses on deploying, monitoring, troubleshooting, backing up, and documenting a Node.js application using practical production support tools and workflows.

The lab includes a Node.js application, Nginx reverse proxy, systemd service management, PostgreSQL database integration, environment-based configuration, logging, log rotation, health checks, uptime monitoring, basic alerting, backup and restore scripts, failure simulation, troubleshooting documentation, a runbook, and a postmortem write-up.
